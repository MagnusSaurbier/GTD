# Open tickets

Work that is written up but **not started**: no branch, no edits. One file per ticket, named
`YYYY-MM-DD-<slug>.md`, from the template in `docs/TICKETS.md`. The moment work starts, the
ticket moves to `docs/in_progress/` (rule 2 in `docs/TICKETS.md`). Unstarted briefs from the
QA pass still live in `docs/follow-ups/` and become tickets when picked up.
